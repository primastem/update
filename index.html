Update PrimaSTEM firmware

1. Open this page in Chrome or Edge. Plug the device into a USB port. Use a cable that transfers data, not a charge-only one.

2. Select device:
3. Select language:

3. Click the Connect button below. In the pop-up window, choose the line that says "USB JTAG/serial debug unit (COM...)".

Leave "Erase device" unchecked. A normal update does not need it. Erasing wipes calibration and the pairing between robot and control board. Use it only if PrimaSTEM support asks you to.
